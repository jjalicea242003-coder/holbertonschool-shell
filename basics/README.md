Basics - Shell Scripts

This directory contains the first basic scripts for the shell project:

- `0-current_working_directory`: A script that prints the absolute path name of the current working directory.

-`1-listit`: A script that displays the list of contents of the current directory.

-`2-bring_me_home`: A script that changes the working directory to the user's home directory.

-`3-listfiles`: A script that display the current directory content in a long format.

-`4-listmorefiles`: A script that display the current content, including hidden files.

-`5-listfilesdigitonly`: A script that display the user's and group IDs numerically.

-`6-firstdirectory`: A script that creates a directory named `my_first_directory` in the /tmp/ directory.

-`7-movethatfile`: A script that moves the file betty from directory /tmp/ to directory /tmp/`my_first_directory`.

-`8-firsdelete`: A script that deletes the file betty in /tmp/`my_first_directory`.

-`9-firstdirdeletion`: A script that deletes the directory `my_first_directory` located in the /tmp/ directory.

-`10-back`: A script that changes the working directory to tje previous one.

-`11-lists`: A script that lists all files (including hidden ones) in the current directory, the parent of the working directory, and the /boot directory in long format.

-`12-file_type`: A script that prints the type of the file named imaafile located in the /tmp directory.
